# Referencia Troko / ESP32

Material conservado únicamente como referencia de una posible mascota física basada en ESP32.

No es parte del desarrollo para Samsung J7:
- El firmware compilado está destinado a una placa ESP32-S3 y periféricos específicos.
- El modelo de palabra de activación incluido está preparado para ESP32-S3.
- Los pines, controladores y procedimiento de flasheo no aplican a Android.
- El flujo de Troko/XiaoZhi puede depender de servicios remotos.

No instalar ni intentar flashear estos archivos en el teléfono. No comprar componentes para esta ruta en la etapa actual.
