# Recursos locales

## caras/
Expresiones animadas GIF. Se utilizarán como recursos visuales locales de la mascota. No cargar todas las animaciones simultáneamente si eso perjudica el rendimiento del J7.

## sonidos/
Efectos OGG opcionales. La aplicación debe permitir silenciarlos y nunca depender de ellos para una función esencial.

## Licencias y atribución
La licencia de XiaoZhi no confirma automáticamente los derechos de cada GIF, sonido o recurso extraído. Antes de distribuir la aplicación o publicar estos archivos en otro proyecto, identificar su autor y licencia. Para prototipos personales, mantener esta advertencia visible en la documentación.
