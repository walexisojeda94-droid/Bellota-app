# Bellota-app

Mascota virtual híbrida para Samsung Galaxy J7, con arquitectura **local-first** y conexión predeterminada a **XiaoZhi oficial (`https://xiaozhi.me`)**.

Con internet, Bellota utilizará XiaoZhi para conversación avanzada. Si se pierde internet o el servicio no responde, la aplicación seguirá funcionando con personalidad, comandos, memoria y voz local de respaldo.

## Regla central

XiaoZhi mejora la experiencia, pero no es un punto único de falla. La interfaz y el núcleo de Bellota permanecen en Android. La PC se utiliza para desarrollar, compilar e instalar, no durante el uso cotidiano.
